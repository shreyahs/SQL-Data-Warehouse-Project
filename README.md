# SQL Data Warehouse Project


## 📌 Project Overview

This project focuses on building a data warehouse using SQL Server, integrating sales data from multiple source systems to support reporting and business analytics.

The project covers the end-to-end data warehousing process, including:

1. **Data Warehouse Architecture:** Design and implement a three-layer architecture (Bronze, Silver, and Gold) to organize data ingestion, transformation, and reporting.
2. **ETL Pipeline Development:** Build SQL-based ETL pipelines to extract, clean, transform, and load data across the warehouse layers.
3. **Data Modeling:** Develop fact and dimension tables to create a structured data model optimized for analytical queries.
4. **Data Analysis:** Use SQL to analyze sales data, identify trends, and generate actionable business insights.

## 🛠️ Project Requirements

### Data Warehouse Development

**Objective**

Build a centralized data warehouse using SQL Server to integrate sales data from ERP and CRM systems, improve data quality, and enable efficient analytical reporting.

**Key Requirements**

- **Data Sources:** Ingest sales data from two source systems (ERP and CRM) using CSV files.
- **Data Quality:** Identify and resolve data quality issues, including missing values, duplicates, and inconsistent formats.
- **Data Integration:** Consolidate data from both source systems into a unified data model for reporting and analysis.
- **Data Scope:** Process the latest available dataset without maintaining historical versions.
- **Documentation:** Document the data warehouse architecture, data models, and transformation logic to support technical and business users.
